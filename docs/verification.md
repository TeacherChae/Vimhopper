# Rhino 검증 목록

에이전트는 Rhino를 실행할 수 없어서 빌드와 단위 테스트까지만 확인합니다. 여기 있는 것은 사람이 Rhino 8에서 직접 확인해야 하는 것입니다. 확인하면 체크하고, 이상하면 항목 옆에 적어 주세요.

## 기반 (1텀 이전)

- [ ] 키 후킹, 한글 IME 끄기·복구, 오버레이 표시
- [ ] 핫 리로드 (`scripts\watch.ps1`로 빌드하면 `Vimhopper: engine reloaded`)
- [ ] 자동 정렬: 그룹 외곽선, 패널·슬라이더 크기, Relay 추가·삭제의 `u` / `Ctrl+r`
- [ ] `dd` / `dL` 후 `u` 한 번에 객체와 남은 객체로 가던 와이어가 함께 돌아옴
- [ ] 켜진 것과 꺼진 것이 섞인 선택에 `gc` → 모두 꺼짐, `u`로 돌아옴
- [ ] `do{n}`으로 와이어 여러 개 끊은 뒤 `u` → `Ctrl+r`
- [ ] 삭제를 `Ctrl+r`로 다시 실행했을 때 커서가 사라진 객체에 남지 않음
- [ ] 비주얼 모드: `H` / `L`로 더한 객체가 커서를 옮겨도 남음, `l l H` 후 `u` 세 번으로 단계별로 돌아옴
- [ ] `gyL`, `gyy` 참조 복사 결과
- [ ] `Space Space`: 검색창이 커서 객체 오른쪽에 뜸, Space 문자가 검색창에 들어가지 않음, 검색창에서 한글 입력
- [ ] `o0` → `Space Space` → 컴포넌트 고르기 → `i0`으로 바로 연결됨
- [ ] Shift+Space, Grasshopper 모드의 Space는 원래 동작 그대로

## 1텀: 문법 완성

- [ ] 점프 목록: `gi0` → `go0` → `Ctrl+o` 두 번으로 처음 객체, `Ctrl+i` 두 번으로 마지막 객체로 돌아옴
- [ ] `3l` 뒤 `Ctrl+o`는 출발 객체로. `l`, `Ctrl+l`은 점프가 아니라서 `Ctrl+o`가 그 전 점프로 감
- [ ] `Space Space`로 컴포넌트를 넣은 뒤 `Ctrl+o`로 넣기 전 객체로 돌아옴
- [ ] 점프 목록의 객체를 `dd`로 지우면 `Ctrl+o`가 건너뛰고, `u`로 되살리면 다시 감
- [ ] Vim 모드의 `Ctrl+O`가 파일 열기 창을 띄우지 않음. Grasshopper 모드의 `Ctrl+O`는 그대로 열림
- [ ] Vim 모드의 `Ctrl+i`가 Grasshopper의 다른 동작을 일으키지 않음
- [ ] 다른 문서 탭으로 바꾸면 `Ctrl+o`가 "점프 목록의 처음입니다"
- [ ] `}` / `{`: 덩어리가 위→아래(같으면 왼쪽→오른쪽) 순서로 바뀌고, 각 덩어리의 맨 왼쪽 열 맨 위 객체에 커서가 내림
- [ ] `3}`로 세 덩어리 건너뜀, 마지막 덩어리에서 `}` → `다음 덩어리 없음`, 첫 덩어리에서 `{` → `이전 덩어리 없음`
- [ ] 비주얼 모드에서 `v}` 하면 선택이 다음 덩어리 첫 객체까지 늘어나고 `u`로 돌아옴
- [ ] `Shift+[` / `Shift+]`가 한글 IME가 켜져 있던 캔버스에서도 `{` / `}`로 동작
- [ ] `yp` → `Ctrl+V`로 덩어리 전체가 붙여넣어짐, `gyp` 참조에 덩어리 전체의 GUID
- [ ] `dp` 후 `u` 한 번에 덩어리가 돌아옴, `gcp` 두 번으로 덩어리가 꺼졌다 켜짐
- [ ] `=p`가 `==`와 같은 결과 (연결 없는 객체에서는 `연결된 객체가 없습니다`)
- [ ] `}` 뒤 `Ctrl+o`로 떠난 객체로 돌아옴
- [ ] 연결 강조: 기본 캔버스(밝은 회색)에서 파란(입력) / 자주색(출력) 굵은 와이어가 잘 보이고, 선택 와이어(초록)·주황 번호와 헷갈리지 않음
- [ ] 연결 강조: 강조 와이어가 Grasshopper 와이어 곡선 위에 정확히 겹침 (확대·축소 여러 단계, 입력이 출력보다 왼쪽에 있는 역방향 와이어 포함), 객체 몸체를 덮지 않음
- [ ] 연결 강조: `h` / `l` 표시가 붙은 객체로 실제 `h` / `l`이 감 (자식이 여럿인 객체, Relay 앞뒤, 마우스로 와이어를 바꾼 직후, `u` 직후)
- [ ] 연결 강조: 출력을 받는 자식이 둘 이상일 때, 한 자식을 다른 자식 위/아래로 드래그하면 `l` 표시가 드래그 중에도 따라감
- [ ] 연결 강조: 와이어 표시를 Hidden / Faint로 둔 입력이 커서에 있으면 일반 굵기·진하기로 강조됨, 커서를 떠나면 원래대로 숨김/흐림
- [ ] 연결 강조: 다른 .gh 파일로 바꾼 뒤에도 강조와 `h` / `l` 표시가 새 문서에서 동작함
- [ ] 연결 강조: 큰 정의(수백 개 객체)에서 캔버스 패닝·확대가 느려지지 않고, `hjkl` 반응이 전과 비슷함
- [ ] 연결 강조: Vim 모드를 끄거나 핫 리로드하면 강조가 사라지고 이전 버전 강조가 남지 않음
- [ ] 다음 키 힌트: `g`, `y`, `d`, `gc`, `2`, `Space`, `o` 뒤 0.4초 기다리면 모드 표시줄 위에 패널이 뜨고, 빨리 이어 치면(`g=`) 뜨지 않음
- [ ] 힌트 패널이 다음 키, `Esc`, `` ` ``(Vim 모드 나가기), 다른 문서로 바꾸기에서 바로 사라짐
- [ ] 확대·축소해도 패널 글자 크기가 같고, 한글 설명이 깨지지 않음
- [ ] 출력 15개 이상인 컴포넌트에서 `o1` 뒤 힌트가 `10..14`와 `Enter`를 보여 줌, `o0`·`i0` 뒤에는 패널이 뜨지 않음
- [ ] `d` 힌트가 뜬 채로 `Shift`를 누르고 있어도 패널이 남고, `H`를 누르면 닫힘. `2y` 힌트의 `h`가 "상류 2단계"
- [ ] 비주얼 모드에서 `g` 힌트가 `y` 선택의 참조 복사 / `c` 선택 켜기/끄기로 바뀜
- [ ] `.`: `dd` 뒤 다른 객체에서 `.` → 그 객체 삭제, `u` 한 번에 하나씩 돌아옴
- [ ] `d2l` 뒤 `3.` → 하류 3단계 삭제, 이어서 `.` → 다시 3단계
- [ ] `gcH` 뒤 `.` → 지금 커서의 상류 전체 끄기/켜기, `3.`도 끝까지 (숫자 무시)
- [ ] 비주얼 `d` / `gc` / `=` 뒤 `.` → 커서 객체만 (`dd` / `gcc` / `==`)
- [ ] `o0f` 뒤 다른 객체에서 `.` → 그 객체의 출력[0]만 flatten, 고른 소스(주황 원)는 그대로
- [ ] `o0` → 이동 → `i1f` 뒤: `o{n}`으로 새 소스를 고르고 다른 객체에서 `.` → 입력[1]에 연결 + flatten. 소스 없이 `.` → 상태줄 오류, flatten도 안 함
- [ ] `di1` 뒤 입력이 하나뿐인 객체에서 `.` → 상태줄 오류
- [ ] `yy`, 이동, `u` 뒤 `.` → 그 전의 변경을 되풀이 (복사·이동·실행 취소는 기억하지 않음)
- [ ] `dd` → 소스 없이 `i1` (오류) → `.` → 여전히 삭제를 되풀이
- [ ] `o0fg` 뒤 다른 객체에서 `.` → `u` 한 번에 flatten·graft 둘 다 되돌아감, Grasshopper Edit 메뉴의 Undo 목록에 하나로 보임
- [ ] 마침표 키와 숫자 패드 `.` 둘 다 동작, 비주얼 모드의 `.`은 오류
- [ ] `dp` 뒤 다른 덩어리에서 `.` / `3.` → 그 덩어리가 삭제되고 `u` 한 번에 돌아옴

## 2텀: 찾기와 점프

먼저 볼 것: **찾기의 한글 입력**(키 후킹이 IME 조합 메시지를 직접 다룸, 가장 위험), 그다음 `p` 붙여넣기의 와이어·undo, 라벨 모양.

### 줌 (`z` 접두어)

- [ ] `z` 한 번만 누르면 아무 일도 없고 힌트에 `z` `h` `l` `H` `L` `p`가 뜸. `zz`가 전의 `z`처럼 커서 객체를 가운데로
- [ ] `zL` / `zH` / `zp`: 범위 전체가 가장자리 여백을 두고 화면 가운데에 들어옴. 지금 배율로 안 들어가면 축소, 들어가면 100%까지만 확대. 300%에서 작은 범위 `zp`는 가운데로만 (배율 그대로)
- [ ] `z2l`, `2zl`, `2z3l`이 각각 2, 2, 6단계 하류를 맞춤
- [ ] 비주얼 모드에서 `z` → 선택이 화면에 맞춰지고 `-- VIM(visual) --`가 그대로, 이어서 `L` / `y`가 됨
- [ ] `Ctrl+=` / `Ctrl+-`: 화면 가장자리 근처의 커서 객체가 확대·축소해도 같은 자리에 머물고 화면이 밀리지 않음. 커서가 없거나 화면 밖이면 화면 가운데 기준
- [ ] 확대·축소 후 와이어·글자·연결 강조·힌트 패널이 어긋나지 않게 다시 그려짐 (`ComputeProjection` 뒤 `Refresh`)
- [ ] 줌 뒤 `u`가 줌이 아니라 그 전의 변경을 되돌리고, `.`이 줌을 되풀이하지 않고, `Ctrl+o`가 줌 전 위치로 가지 않음
- [ ] 최대·최소 배율(500% / 10%)에서 Grasshopper 휠 줌과 섞어 써도 화면이 튀지 않음

### 라벨 점프 (`t`)

- [ ] `t` → 화면에 보이는 객체마다(커서 객체 제외) 분홍 바탕 라벨이 객체 가운데에 뜨고, 커서에 가까운 객체가 `a` `s` `d` `f` …를 받음
- [ ] 라벨을 치면 그 객체로 커서가 옮겨 가고 라벨이 사라짐. `Ctrl+o`로 원래 자리로 돌아옴
- [ ] 확대·축소해도 라벨 글자 크기가 같음. 화면 가장자리에 반쯤 걸친 객체는 중심이 화면 안일 때만 라벨을 받음
- [ ] 객체가 27개 이상 보이는 화면: 먼 객체가 두 글자 라벨(`ma` 등)을 받고, 첫 글자를 치면 그 글자로 시작하지 않는 라벨이 사라지고 친 글자는 흐려짐. `Backspace`로 첫 글자 지우기
- [ ] `Esc` → `라벨 점프 취소`, 라벨이 아닌 키(`x`, `h`) → `라벨이 아닙니다: 라벨 점프 취소`. 그 키로 이동하지 않음
- [ ] 화면에 커서 객체뿐일 때 `t` → `라벨을 붙일 객체가 화면에 없습니다`
- [ ] `o0 t{라벨} i1` → 출력[0]이 라벨 객체의 입력[1]에 연결됨. `o0 t Esc` 뒤에도 주황 원(소스)이 남음
- [ ] 비주얼 모드 `v t{라벨}` → 시작점과 라벨 객체 사이 블록이 선택됨, 비주얼 `u`로 되돌림
- [ ] `yt{라벨}` → `Ctrl+V`로 붙이면 `v t{라벨} y`와 같은 객체들. `dt{라벨}` / `gct{라벨}` / `=t{라벨}` / `gyt{라벨}`도 같은 블록, `u` 한 번에 돌아옴
- [ ] `dt{라벨}` 뒤 `.` → 그 전의 변경을 되풀이 (라벨 범위는 되풀이하지 않음)
- [ ] `y` 뒤 0.4초 힌트에 `t 라벨 대상까지 블록`이 보이고, `t` 뒤에는 힌트 패널이 뜨지 않음. HUD에 `t` / `dtm`처럼 입력 중인 키가 보임
- [ ] 라벨이 떠 있는 채로 `` ` ``(Vim 모드 끄기), 다른 문서로 바꾸기, 핫 리로드 → 라벨이 사라짐

### 마크와 붙여넣기

- [ ] `ma` → 다른 곳으로 이동 → `'a`로 돌아옴, 이어서 `Ctrl+o`로 떠난 객체로 돌아옴
- [ ] `'` 뒤 0.4초 힌트에 설정한 마크와 객체 이름이 뜸 (없으면 `설정된 마크 없음`), `m` 뒤 힌트는 `{a-z}`
- [ ] `'b`(설정 안 함), `mA`, `m1` → 상태줄 오류
- [ ] 마크한 객체를 `dd` → `'a` → `마크 a의 객체가 지워졌습니다`, `u` 뒤 `'a`로 다시 감
- [ ] 문서 두 개에 각각 `ma` → 탭을 바꿔 가며 `'a`가 그 문서의 객체로 감. 한 문서를 닫았다 다시 열면 그 문서의 `'a`는 `마크 a가 없습니다`
- [ ] 비주얼 모드에서 `v'a` → 선택이 마크 객체까지 늘어나고 `u`로 돌아옴
- [ ] 비주얼 모드에서 `p`, `2p`, `3P` → 아무 일도 없고 상태줄 오류도 없음, 비주얼 모드 그대로
- [ ] `y'a` → `Ctrl+V`로 붙이면 `v'a y`와 같은 객체들. `d'a` / `gc'a` / `='a` / `gy'a` / `z'a`도 같은 블록, 변경은 `u` 한 번에 돌아옴
- [ ] `2d'a`, `d2'a` → `d'a`와 같음. HUD에 `2d'` / `d2'`가 보임, `d` 뒤 0.4초 힌트에 `' 마크 객체까지 블록`, `d'` 뒤 힌트에 설정된 마크
- [ ] `d'b`(설정 안 함) → `마크 b가 없습니다`, 마크 객체를 지운 뒤 `y'a` → `마크 a의 객체가 지워졌습니다`. 둘 다 아무것도 바뀌지 않음
- [ ] `gc'a` → 다른 객체로 옮겨 `.` → 거기서 마크 a까지 켜기/끄기. `d'a` 뒤 `.` → `마크 a의 객체가 지워졌습니다`
- [ ] `='a` → 블록 안 덩어리가 따로 정렬됨 (`=t{라벨}`과 같음)
- [ ] `'` 키가 한글 IME가 켜져 있던 캔버스에서도 동작
- [ ] `yy` → 다른 객체에서 `p` → 오른쪽에 붙고 가운데 높이가 맞음, 커서가 붙인 객체로. `P`는 왼쪽에
- [ ] `yL`(여러 객체) → `p` → 배치와 내부 와이어가 그대로, 커서는 왼쪽 열 맨 위 객체. 클립보드 밖 소스에서 오던 입력 와이어도 이어짐 (`Ctrl+V`와 같은지)
- [ ] `p` 뒤 `u` 한 번에 붙인 객체가 모두 사라짐, `Ctrl+r`로 다시 생김. Edit 메뉴 Undo 목록에 하나로 보임
- [ ] `p` 뒤 `.` 두 번 → 오른쪽으로 이어 붙음, 붙인 객체끼리 GUID가 겹치지 않음 (`gyy`로 확인)
- [ ] `p` 뒤 `Ctrl+o` → 붙이기 전 객체로
- [ ] 마우스로 다른 곳에 커서를 둬도 `p` 위치가 마우스와 무관
- [ ] 객체가 없는 빈 문서에서 `p` → 화면 가운데에 붙음
- [ ] 클립보드에 텍스트만 있을 때 `p` → `클립보드에 Grasshopper 객체가 없습니다`
- [ ] 다른 Rhino 세션이나 Grasshopper `Ctrl+C`로 복사한 것도 `p`로 붙음
- [ ] 비주얼 모드의 `p` / `P`는 아무 일도 하지 않음
- [ ] 비주얼 모드에서 `ma`, `3ma` 둘 다 마크를 달고 비주얼 모드가 유지됨
- [ ] 출력이 있는 컴포넌트(예: 슬라이더 → Addition)를 `yL` → `p` → `p` → 두 번째로 붙인 것도 출력 값이 새로 계산됨 (패널·미리보기로 확인, 오래된 데이터나 주황/빨강 경고 없음)
- [ ] 스크리블만 복사해서 `p` → 스크리블은 붙고, 커서는 원래 객체에 남고 `Ctrl+o` 목록에 기록되지 않음

### 찾기

- [ ] `/` → 모드 표시줄 자리에 `/` 입력줄, 치는 동안 맞는 객체 노란 테두리·다음 대상 주황 테두리, 커서와 화면이 따라감, 입력줄 끝에 `[2/5]`
- [ ] `/` 입력 중 `Esc` → 커서·화면이 `/` 전으로. 빈 줄에서 `Backspace` → 취소. `Ctrl+u` 모두 지우기, `Ctrl+v` 붙여넣기
- [ ] 입력줄에 친 글자(`h`, `d`, `Space` 등)가 Vim 명령이나 Grasshopper 동작(검색창 등)을 일으키지 않음
- [ ] 한글: 한/영을 한글로 두고 `/` → `반지름`처럼 별명을 쳐서 찾아짐. 조합 중인 글자가 입력줄에 주황 밑줄로 보이고 IME 기본 조합 창이 따로 뜨지 않음
- [ ] 한글 조합 중에 `Enter` → 조합 글자까지 넣어 찾음. 조합 중에 `Esc` → 조합만 지워짐(한 번 더 `Esc`로 닫힘)
- [ ] 입력줄을 닫은 뒤 Vim 모드에서 `h`가 다시 `ㅗ`가 되지 않음 (IME 다시 꺼짐), Vim 모드를 나가면 IME가 원래대로
- [ ] 입력 중에 `` ` ``로 Vim 모드를 나가거나 다른 문서 탭으로 바꾸면 입력줄이 닫히고 IME가 Grasshopper 모드 상태로 돌아옴, 핫 리로드해도 남지 않음
- [ ] `Enter`로 이름·별명·탭 이름(예: `maths`)으로 찾아짐, 대소문자 무시. 순서가 덩어리 → 왼쪽 열 → 위→아래
- [ ] 마지막 대상에서 `n` → 처음으로 돌고 `search hit BOTTOM, continuing at TOP`, `N`은 반대. `3n`이 세 개 건너뜀
- [ ] 빈 `/` `Enter`가 마지막 찾기를 되풀이, 찾기 전이면 `이전 검색어가 없습니다`
- [ ] `*` / `#`: 커서와 같은 종류(예: Number Slider)의 다음 / 이전 객체로, `#` 뒤 `n`은 뒤로
- [ ] 찾기 뒤 `Ctrl+o`로 출발 객체로 돌아옴. 비주얼 모드에서 `n` / `/…Enter`로 선택이 늘어나고 `u`로 돌아옴
- [ ] `o0n`은 여전히 Invert, `o0` → `/이름` `Enter` → `i1`로 원격 연결
- [ ] 커서 객체 없이(빈 캔버스 쪽에서 Vim 모드) `/` → 미리 보기 뒤 `Esc` → 아무것도 선택되어 있지 않음. 커서 없이 `*` → `커서 객체가 없습니다`, 커서가 생기지 않음
- [ ] 입력줄이 열린 동안 `Ctrl+S` / `Ctrl+Z`가 저장·실행 취소를 하지 않음 (메뉴 단축키가 먼저 처리되면 적어 주세요)
- [ ] 입력줄이 열린 동안 `` ` `` → 찾기가 버려지고 Vim 모드가 꺼짐, IME가 Grasshopper 모드 상태로. 한글 상태에서 `` ` ``가 입력줄 글자로 들어가면 적어 주세요
- [ ] 한글 음절을 조합하는 중(예: `반지` 다음 `ㄹ`까지 친 상태)에 `Enter` → 조합 중인 글자까지 넣어 한 번에 찾고, 입력줄이 닫힌 뒤 글자가 캔버스나 다른 곳에 새로 찍히지 않음
- [ ] US·한국어 키보드에서 `/`(물음표 키), `Shift+8` `*`, `Shift+3` `#`, 숫자 패드 `/` `*`이 동작

## 3텀: 읽기와 진단

먼저 볼 것: `]e`의 원인 판정(Relay 너머 포함), `K`의 개수가 flatten/graft 적용 뒤 값인지, `gG`로 만든 그룹이 `Ctrl+G` 그룹과 같은 모양·그리기 순서인지, `cn`의 한글 입력과 `u`.

### `]` / `[` 다음·이전

- [ ] 슬라이더(텍스트) → Addition(오류) → Relay → Multiplication(오류) 사슬: `]e`가 Addition에만 가고 상태줄 `오류 원인 1/1 (오류 2개)`와 첫 메시지
- [ ] 경고 사슬(입력 빠진 컴포넌트 → 하류 경고): `]w`가 맨 위 경고 객체에만 감. 오류 하류의 경고는 건너뜀
- [ ] `3]e`, `[e`, 끝에서 `]e` → 처음으로 돌고 `search hit BOTTOM, continuing at TOP`
- [ ] `]e` 뒤 `Ctrl+o`로 원래 자리. 비주얼 모드 `v]e` → 선택이 늘고 비주얼 `u`로 되돌림
- [ ] Vim 모드에서 느린 객체 5개 오른쪽 위에 `12 ms` 같은 라벨, 줌해도 같은 크기. Vim 모드 끄면 사라짐
- [ ] 시간이 0인 객체(예: 꺼 둔 컴포넌트)에서 `]s` → 가장 느린 객체, `[s` → 가장 빠른 객체. 순위 안에서는 `]s`가 한 단계 빠른 쪽, `[s`가 한 단계 느린 쪽. 상태줄 시간이 Grasshopper Profiler와 같은지
- [ ] `]g` → 그룹의 왼쪽 위 열 첫 객체로, 상태줄에 그룹 이름. 스크리블만 든 그룹은 건너뜀
- [ ] 그룹 안에 그룹(바깥 `Outer`, 안쪽 `Inner`)을 만들어 첫 멤버가 같게 → `]g`가 그 객체에 한 번만 서고 상태줄이 `그룹 n/m Inner`. 안쪽 그룹을 먼저 만들든 나중에 만들든 같음
- [ ] `]` 뒤 0.4초 힌트에 `e` `w` `s` `g`, `]x` → 오류, `]` `Esc` → 취소
- [ ] 한글 IME가 켜진 상태에서도 `]` `[`가 들어옴

### 데이터 모양 (`K`)

- [ ] 컴포넌트에서 `K`: 커서 객체 옆에 입력·출력 패널, 가지·항목·null·타입 수가 Grasshopper 패널/툴팁과 같음
- [ ] flatten/graft/simplify/reverse를 건 입력은 연산자가 보이고 개수가 적용 뒤 값
- [ ] 가지 10개 vs 3개, 항목 100개 vs 1개 입력에 짝 맞춤 힌트. 슬라이더끼리는 힌트 없음
- [ ] `K` 뒤 `j`: 패널이 닫히고 이동함. `K` 두 번, `Esc`는 닫기만
- [ ] 패널이 화면 오른쪽 끝에서는 객체 왼쪽에 뜸. 줌과 무관하게 같은 크기
- [ ] 꺼진 객체·계산 전 객체·그룹에서 `K`: 상태줄 메시지
- [ ] 패널이 열린 채 `` ` `` / 문서 바꾸기 / 핫 리로드: 패널이 남지 않음

### 그룹 (`gG`)

- [ ] `gGp` → 덩어리에 초록 점선 테두리, 입력줄 `그룹 이름: `과 끝에 `객체 n개`. `입력` `Enter` → 덩어리를 감싸는 `입력` 그룹 (기본 그룹 색, Ctrl+G로 만든 그룹과 같은 모양)
- [ ] 한/영을 한글로 두고 `gGG` → `반지름` 입력, 조합 중 `Enter` → 그룹 이름이 `반지름`. 닫은 뒤 `h`가 `ㅗ`가 되지 않음
- [ ] 빈 이름 `Enter` → 이름 없는 그룹. `Esc` → 그룹이 생기지 않고 `u`로 되돌릴 것도 없음 (Edit 메뉴의 Undo 목록이 그대로)
- [ ] 그룹을 만든 뒤 `u` 한 번 → 그룹만 없어지고 객체는 그대로, `Ctrl+r` → 그룹이 다시 생김
- [ ] `gG2l`, `2gGl`, `gGH`, `gG'a`, `gGt{라벨}`이 각 범위를 묶음. Relay가 낀 범위면 Relay도 그룹 안에
- [ ] 이미 그룹에 든 객체를 `gGG` → 새 그룹이 생기고 원래 그룹도 그 객체를 그대로 감쌈 (겹친 그룹)
- [ ] `v` 로 몇 개 고른 뒤 `gG` → 비주얼 모드가 끝나고 선택했던 객체들이 이름을 받아 묶임
- [ ] Grasshopper 모드에서 기존 그룹을 마우스로 함께 골라 비주얼 선택에 넣은 뒤(또는 블록에 그룹이 들어가게) `gG` → 그 그룹이 새 그룹 안에 겹쳐 들어감 (Ctrl+G로 그룹을 묶은 것과 같은 모양)
- [ ] `gGl` `이름` `Enter` 뒤 다른 객체에서 `.` → 묻지 않고 같은 이름 `이름`으로 하류 한 단계를 묶음, `3.` → 하류 3단계, `u` 한 번에 하나씩 되돌아감
- [ ] 이름 입력 중에 `` ` ``로 Vim 모드를 나가거나 문서 탭을 바꾸면 입력줄과 점선 테두리가 사라지고 그룹이 생기지 않음
- [ ] 그룹을 만든 뒤 파일을 저장·다시 열어도 그룹과 이름이 남음

### 별명 바꾸기 (`cn`)

- [ ] 컴포넌트에서 `cn` → 입력줄 `별명: 지금별명`, 커서는 끝. 글을 고쳐 `Enter` → 별명이 바뀌고 컴포넌트 폭이 새 별명에 맞게 다시 그려짐
- [ ] 한글 별명(`점수`) 입력, 조합 중 `Enter`도 조합 글자까지 들어감
- [ ] `u` 한 번에 원래 별명, `Ctrl+r`로 다시. 별명을 바꿔도 다시 계산되지 않음 (다시 계산돼야 하는 객체가 있으면 적어 주세요)
- [ ] 빈 `Enter` → 기본 별명 (Addition → `A+B`, 슬라이더, 패널, 그룹). `기본 별명을 찾을 수 없습니다`가 나오는 종류가 있으면 적어 주세요
- [ ] `Esc` → 그대로, `c` 다음 `x` → 오류, `c Esc` → 취소
- [ ] `cn` → `Enter` 뒤 다른 객체에서 `.` → 묻지 않고 같은 별명
- [ ] `dd` 뒤 `cn` → 고치지 않고 `Enter` → `별명이 그대로입니다`, 이어서 `.`은 여전히 `dd`
- [ ] `cn` 입력 중 마우스로 다른 객체를 골라도 `Enter`는 처음 객체의 별명을 바꿈
- [ ] 파라미터(슬라이더, 패널, Relay)도 바뀜. 커서가 그룹·스크리블에 갈 수 있게 되면: 그룹은 이름이 바뀌고 스크리블은 `별명이 없는 객체입니다`
- [ ] 비주얼 모드에서 `c`는 아무 일도 없고 `gc`는 그대로 켜기/끄기

## 4텀: 명령줄과 설정

### 명령줄 (`:`)

- [ ] `:` → 모드 표시줄 자리에 `:` 입력줄. `Esc`로 닫힘, 빈 `Enter`는 아무 일 없음, 한글도 쳐짐
- [ ] `:w` → 저장됨 (탭 제목의 `*`가 사라짐, 대화상자 없음). 새 문서(저장한 적 없음)에서 `:w` → `저장한 적 없는 문서입니다` 오류
- [ ] `:rec` `Enter` → F5처럼 모든 객체가 다시 계산됨
- [ ] `:lock` → 툴바의 솔버 잠금 표시가 바뀌고 슬라이더를 움직여도 계산 안 됨. `:unl` → 풀리고 바로 계산됨. 잠근 채 `:rec` → `솔버가 잠겨 있습니다`
- [ ] `:rh _Line` → Rhino 명령창에서 Line이 시작됨 (Grasshopper 창에 포커스가 있어도). `:rh _Circle 0,0,0 5` → 원이 바로 그려짐
- [ ] `:un` `Enter` → 지금은 `:unlock`이 실행됨 (설정 작업이 `:unmap`을 더하면 `모호한 명령` 오류), `:xyz` → `명령이 아닙니다`
- [ ] `:re` `Tab` → `:recompute`. `:` `Tab` → 후보가 오른쪽에 보이고 `Tab`마다 다음 후보, `Shift+Tab`은 앞으로. **`Tab`이 입력줄에 오지 않고 포커스가 다른 컨트롤로 넘어가면** 적어 주세요
- [ ] `:w`, `:rec` 실행 뒤 `:` `↑` → `rec`, 다시 `↑` → `w`, `↓` → `rec`. `:r` 치고 `↑` → `r`로 시작하는 줄만. `Ctrl+p` / `Ctrl+n`도 같음. 방향키가 객체를 움직이지 않음
- [ ] 컴포넌트에서 `:s/A/X/` → 별명의 첫 `A`만 바뀜, `g`면 모두, `i`면 대소문자 무시. `:s#/#-#g`처럼 다른 구분자. `:s/(\w+)/[$1]/` 정규식 그룹
- [ ] `:%s/x/y/g` → 문서의 모든 별명이 바뀌고 상태줄에 `n개 바꿈`. `u` 한 번에 모두 되돌아오고 `Ctrl+r`로 다시. 다시 계산되지 않음. 그룹 이름도 바뀜
- [ ] 비주얼 모드로 몇 개 고른 뒤 `:` → `:'<,'>`가 채워져 있음. `s/a/b/` `Enter` → 고른 것만 바뀌고 비주얼 모드를 나감. `v` `:` `Esc` → 비주얼 모드를 나감 (vim과 같음)
- [ ] 맞는 것이 없으면 `맞는 별명이 없습니다`, 패턴 오류(`:s/(/x/`)는 상태줄에 오류, undo 기록이 생기지 않음
- [ ] `:s` 뒤 `.`은 `:s`가 아니라 그 전 변경을 되풀이함
- [ ] 명령줄을 연 채 `` ` ``로 Vim 모드를 나가거나 문서 탭을 바꾸면 입력줄이 닫히고 실행되지 않음
