# Rhino 검증 목록

에이전트는 Rhino를 실행할 수 없어서 빌드와 단위 테스트까지만 확인합니다. 여기 있는 것은 사람이 Rhino 8에서 직접 확인해야 하는 것입니다. 확인하면 체크하고, 이상하면 항목 옆에 적어 주세요.

## 기반 (1텀 이전)

- [ ] 키 후킹, 한글 IME 끄기·복구, 오버레이 표시
- [ ] 핫 리로드 (`scripts\watch.ps1`로 빌드하면 `Vimhopper: engine reloaded`)
- [ ] 자동 정렬: 그룹 외곽선, 패널·슬라이더 크기, Relay 추가·삭제의 `u` / `Ctrl+r`
- [ ] `dd` / `dL` 후 `u` 한 번에 객체와 남은 객체로 가던 와이어가 함께 돌아옴
- [ ] 켜진 것과 꺼진 것이 섞인 선택에 `gc` → 모두 꺼짐, `u`로 돌아옴
- [ ] `do{n}`으로 와이어 여러 개 끊은 뒤 `u` → `Ctrl+r`
- [ ] 삭제를 `Ctrl+r`로 다시 실행했을 때 커서가 사라진 객체에 남지 않음
- [ ] 비주얼 모드: `H` / `L`로 더한 객체가 커서를 옮겨도 남음, `l l H` 후 `u` 세 번으로 단계별로 돌아옴
- [ ] `gyL`, `gyy` 참조 복사 결과
- [ ] `Space Space`: 검색창이 커서 객체 오른쪽에 뜸, Space 문자가 검색창에 들어가지 않음, 검색창에서 한글 입력
- [ ] `o0` → `Space Space` → 컴포넌트 고르기 → `i0`으로 바로 연결됨
- [ ] Shift+Space, Grasshopper 모드의 Space는 원래 동작 그대로

## 1텀: 문법 완성

- [ ] `.`: `dd` 뒤 다른 객체에서 `.` → 그 객체 삭제, `u` 한 번에 하나씩 돌아옴
- [ ] `d2l` 뒤 `3.` → 하류 3단계 삭제, 이어서 `.` → 다시 3단계
- [ ] `gcH` 뒤 `.` → 지금 커서의 상류 전체 끄기/켜기, `3.`도 끝까지 (숫자 무시)
- [ ] 비주얼 `d` / `gc` / `=` 뒤 `.` → 커서 객체만 (`dd` / `gcc` / `==`)
- [ ] `o0f` 뒤 다른 객체에서 `.` → 그 객체의 출력[0]만 flatten, 고른 소스(주황 원)는 그대로
- [ ] `o0` → 이동 → `i1f` 뒤: `o{n}`으로 새 소스를 고르고 다른 객체에서 `.` → 입력[1]에 연결 + flatten. 소스 없이 `.` → 상태줄 오류, flatten도 안 함
- [ ] `di1` 뒤 입력이 하나뿐인 객체에서 `.` → 상태줄 오류
- [ ] `yy`, 이동, `u` 뒤 `.` → 그 전의 변경을 되풀이 (복사·이동·실행 취소는 기억하지 않음)
- [ ] `dd` → 소스 없이 `i1` (오류) → `.` → 여전히 삭제를 되풀이
- [ ] `o0fg` 뒤 다른 객체에서 `.` → `u` 한 번에 flatten·graft 둘 다 되돌아감, Grasshopper Edit 메뉴의 Undo 목록에 하나로 보임
- [ ] 마침표 키와 숫자 패드 `.` 둘 다 동작, 비주얼 모드의 `.`은 오류
