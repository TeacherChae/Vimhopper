# 0012. Vim 모드의 Space는 리더, 컴포넌트 넣기는 `Space Space`, `:`는 명령줄

- 상태: 채택 (2026-11-05)
- 관련: [리더 키, 컴포넌트 검색, 줌](../leader-and-zoom-ideas.md), [키맵 — 넣기](../keymap.md#넣기)

## 맥락

Grasshopper의 `Space`는 컴포넌트 검색창이라 사용자 손에 깊이 배어 있습니다. 한편 nvim 사용자는 Space 리더에 익숙하고, 앞으로 사용자 매핑을 얹을 자리가 필요합니다.

## 결정

- **Vim 모드에서만** `Space`를 리더로 가져갑니다. Grasshopper 모드의 `Space`는 그대로.
- `Space Space` = 커서 객체 오른쪽에 Grasshopper 검색창(`GH_Canvas.ShowComponentSearchBox(Point)`)을 띄우고, 놓인 컴포넌트로 커서를 옮깁니다. 검색창은 Space 키 처리가 끝난 뒤(`BeginInvoke`) 띄웁니다.
- 기본 기능은 리더를 쓰지 않고 `g` `z` `[` `]` 접두어로 나눕니다. `Space` 다음의 다른 키는 사용자 매핑용으로 비워 둡니다 (4텀 키맵 설정).
- `:`는 검색창이 아니라 Vimhopper 자체의 명령줄(HUD 입력줄)로 둡니다 (4텀).

## 결과

- `o0 Space Space (넣기) i0`로 새 컴포넌트에 바로 연결.
- 검색창 안 키가 훅에 걸리지 않는지, 한글 IME, 놓이는 위치는 Rhino 확인 필요.

## 버린 대안

| 대안 | 버린 이유 |
|---|---|
| `\` 리더 | 손이 멂 |
| `,` 리더 | 나중에 `f` / `;` / `,`를 들여오면 겹침 |
| `:`로 검색창 | `:`는 모든 명령을 받는 자리로 남김 |
