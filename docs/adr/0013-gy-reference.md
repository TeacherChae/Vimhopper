# 0013. `gy`는 `파일 경로:GUID,GUID` 텍스트

- 상태: 채택 (2026-10-30, 연산자로 바꾼 것은 2026-11-05)
- 관련: [키맵 — 복사](../keymap.md#복사)

## 맥락

`y`는 붙여넣을 객체 자체(Grasshopper 클립보드 XML)를 복사합니다. 그 밖에 객체를 **가리키는** 텍스트가 필요했습니다: 이슈·메모·AI 에이전트에게 "이 컴포넌트"를 전달하기.

## 결정

- 에디터의 `파일:줄`처럼 `파일 경로:InstanceGuid`. 여러 개면 경로는 한 번, GUID는 쉼표로.
- 저장한 적 없는 문서는 GUID만.
- `gy`는 연산자라 범위를 받습니다 (`gyL`). `gyy`만 예외로 Grasshopper 선택 전체 (마우스로 고른 것 포함). 왼쪽 열부터, 같은 열은 위부터.

## 결과

- `.ghx`에서는 GUID로 바로 찾을 수 있지만 `.gh`(바이너리)는 안 됩니다.
- 3텀 이후 "`.gh` 비교용 텍스트 내보내기"와 이어질 수 있습니다.
