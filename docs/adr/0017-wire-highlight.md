# 0017. 커서 객체의 연결은 Vim 모드에서 늘 강조

- 상태: 채택 (2026-11-09)
- 관련: [키맵 — 연결 강조](../keymap.md#연결-강조), `WireHighlight.cs`

## 맥락

스파게티 와이어는 Grasshopper 사용자 불편 1위입니다 ([사용자 조사](../research/grasshopper-users.md)). 배치를 바꾸지 않고 보이는 방식만으로 덜 수 있는 부분이 있습니다.

## 결정

- 키를 누르지 않아도 Vim 모드에서 커서 객체의 입력 와이어(파랑)·출력 와이어(자주)를 굵게, `h` / `l`이 갈 객체에 외곽선과 글자.
- Grasshopper와 같은 곡선(`GH_Painter.ConnectionPath`)을 일반 와이어 위, 객체 아래에 다시 그립니다.
- 숨김·흐림으로 둔 와이어도 커서에 있으면 일반 굵기로 보입니다 (의도).
- `h` / `l` 대상은 이동과 같은 코드(`GraphNavigator.Hops`)로 정해 실제 이동과 어긋나지 않습니다.
- Relay 너머는 강조하지 않습니다.
- 비용: 와이어는 매 프레임 커서 파라미터만, `h` / `l` 대상은 커서·문서가 바뀔 때만 다시 계산.

## 결과

- 끄는 설정은 아직 없습니다 (4텀 `:set` 후보).
