# 0009. 덩어리(와이어로 이어진 객체들)가 문단: `p` 범위, `{` / `}`

- 상태: 채택 (2026-11-09)
- 관련: [키맵 — 덩어리 이동](../keymap.md#덩어리-이동), `GraphRange.Island`, `GraphNavigator.Island`

## 맥락

vim의 문단(`ip`, `{` `}`)에 해당하는 단위가 필요했습니다. Grasshopper 정의는 서로 이어지지 않은 여러 흐름으로 나뉘고, `==`가 이미 그 단위로 정렬하고 있었습니다.

## 결정

- 덩어리 = 와이어 방향과 무관하게 이어진 객체 전부 (Relay 포함). 연결 없는 객체 하나도 덩어리.
- 연산자 뒤 `p` = 덩어리 전체 (`yp` `dp` `gcp`, `=p` = `==`). 단계가 없어서 숫자를 무시합니다.
- `}` / `{` = 다음 / 이전 덩어리의 첫 객체 (가장 상류 열의 맨 위, Relay 제외). 순서는 `g=`가 쌓는 순서(위쪽 끝 → 왼쪽 끝). 끝에서 처음으로 돌아가지 않습니다. `{`는 지금 덩어리의 처음이 아니라 이전 덩어리로.
- vim의 `ip`(inner)가 아니라 `p` 한 글자인 이유: Vimhopper에는 아직 텍스트 객체(`i`/`a`) 문법이 없고 `i`는 연결에 쓰입니다.

## 결과

- 비주얼 모드의 `p`는 범위가 아니라 비어 있습니다. 2텀의 붙여넣기 `p`는 노멀 모드 `p`입니다 (연산자 뒤 `p`와 겹치지 않음).
