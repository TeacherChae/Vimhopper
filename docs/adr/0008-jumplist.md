# 0008. 점프 목록: 무엇이 점프인지는 Vimhopper가 정함

- 상태: 채택 (2026-11-09)
- 관련: [키맵 — 점프 목록](../keymap.md#점프-목록), `JumpList.cs`, `VimController.RecordJump`

## 맥락

`h`/`l`이 서로의 역이 아니어서 왔던 곳으로 돌아갈 방법이 필요했습니다. vim의 jumplist(`Ctrl+o` / `Ctrl+i`)가 답이지만, vim의 "점프"(검색, `G`, `%` …)는 Grasshopper에 그대로 대응하지 않습니다.

## 결정

| 점프 | 점프 아님 |
|---|---|
| `gi{n}` `go{n}`, `{` `}`, 숫자를 붙인 이동(`3l`), `Space Space`로 넣은 객체로 옮김 | `hjkl`, `Ctrl+hjkl`, `dd` 뒤 이웃으로 옮김 |

- 숫자 이동을 점프로 치는 것은 vim과 다른 Vimhopper 규칙입니다 (그래프에서 몇 단계 건너뛰면 화면에서 멀리 감).
- 같은 객체는 목록에 한 번만(최근 것), 최대 100개. 끝에서 처음 `Ctrl+o`하면 지금 자리도 저장. 돌아간 뒤 새로 점프해도 뒤쪽은 지우지 않음 (vim 기본).
- 지운 객체는 건너뜀. 다른 문서로 바꾸면 비움, Vim 모드를 껐다 켜도 유지.
- **앞으로 만드는 멀리 가는 이동(찾기 `/` `n`, 마크 `'`, 라벨 점프 `s`)은 `RecordJump`를 부릅니다.**

## 결과

- `Ctrl+o`가 Grasshopper의 열기를 가립니다 ([0002](0002-key-hook.md)). 메뉴 단축키가 먼저 처리되는지 Rhino에서 확인해야 합니다.
