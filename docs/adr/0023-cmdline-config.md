# 0023. `:` 명령줄, `:s` 범위, 설정 파일은 명령 줄 모음, `Ctrl+a` / `Ctrl+x`

- 상태: 채택 (2026-11-10)
- 관련: [로드맵 4텀](../roadmap.md#4텀-명령줄과-설정), [0012 리더](0012-leader-space.md), [0020 찾기 입력줄](0020-search.md), [리더·검색·줌·명령줄](../leader-and-zoom-ideas.md#4--명령줄)

## 맥락

Grasshopper에는 명령줄이 없고 메뉴 항목이 사실상 명령 목록입니다. 키맵 설정 파일과 사용자 매핑은 리더 키(`Space`)를 비워 둔 이유였습니다. vim 사용자는 `:` 명령과 `vimrc`에 익숙합니다.

## 결정

- `:`는 `/`와 같은 HUD 입력줄. 명령 이름은 vim처럼 겹치지 않는 앞부분만 써도 됩니다 (`:rec` = `:recompute`). `Tab` 완성, `↑` / `↓` 기록.
- 첫 명령: `:w` 저장, `:recompute` 다시 계산, `:lock` / `:unlock` 솔버, `:rh {Rhino 명령}` Rhino 명령 실행, `:s`, `:map` 계열, `:set`, `:source`.
- `:s/찾을/바꿀/[gi]`는 별명(NickName)을 바꿉니다. 범위: 없으면 커서 객체, `%`는 문서 전체, 비주얼 모드에서 `:`는 `'<,'>`가 미리 채워져 선택한 객체. 패턴은 .NET 정규식, `g` 모두 바꾸기, `i` 대소문자 무시. `u` 한 번에 되돌아갑니다. `.`으로 되풀이하지 않습니다 (vim과 같음).
- 설정 파일 `%APPDATA%\Vimhopper\vimhopperrc`는 `:` 명령을 한 줄에 하나씩 적은 것입니다 (vimrc와 같은 방식, `"`로 시작하면 주석). Vim 모드에 처음 들어갈 때와 `:source`로 읽습니다.
- 매핑: `map` / `noremap` (일반·비주얼), `nmap` / `nnoremap`, `vmap` / `vnoremap`, `unmap`. 표기는 vim과 같습니다 (`<Space>`, `<leader>`, `<C-x>`, `<Esc>`, `<CR>`). `<leader>`는 `Space`로 고정합니다.
- `Ctrl+a` / `Ctrl+x`: 커서 객체가 Number Slider면 값을 한 단계 올리고 / 내립니다 (`{n}Ctrl+a`는 n단계). `.`으로 되풀이하고 `u` 한 번에 되돌아갑니다. Vim 모드에서는 Grasshopper의 `Ctrl+A`(모두 선택) / `Ctrl+X`(잘라내기)를 가져갑니다.

## 결과

- 설정 파일 문법을 따로 만들지 않아서, 파일에 쓰는 것은 `:`로 바로 시험해 볼 수 있습니다.
- `Ctrl+A` 모두 선택은 Vim 모드에서 쓸 수 없습니다 (Grasshopper 모드나 메뉴로).
