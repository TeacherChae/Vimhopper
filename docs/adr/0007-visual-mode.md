# 0007. 비주얼 범위는 두 끝을 감싸는 직사각형, `u`는 선택 되돌리기

- 상태: 채택 (2026-10-28, `u`는 2026-11-05)
- 관련: [키맵 — 비주얼 모드](../keymap.md#비주얼-모드)

## 맥락

여러 객체를 고르는 키보드 방법이 필요했습니다. vim의 비주얼 모드는 두 끝(시작점과 커서)으로만 범위가 정해집니다.

## 결정

- 범위 = 시작점과 커서 두 객체를 감싸는 **화면상 직사각형** 안에 중심이 들어오는 객체. 지나온 경로와 무관합니다. 정렬된 화면에서는 열·행 블록이 됩니다.
- `o`는 양 끝 바꾸기, `H` / `L`은 지금 선택의 상류 / 하류 전체를 더함 (커서를 옮겨도 남음).
- 연산자(`y` `gy` `=` `d` `gc`)는 범위 없이 선택에 바로 실행하고 모드를 나갑니다.
- 비주얼 모드의 `u`는 실행 취소가 아니라 **선택을 한 단계 전으로** 되돌립니다 (`h`/`l`이 서로의 역이 아니라서 커서를 되돌려도 원래 선택으로 안 돌아올 수 있기 때문, [0005](0005-hjkl-follows-wires.md)).

## 결과

- 범위(직사각형)와 이동(와이어)의 기준이 달라서, `h`로 "왼쪽 열까지" 넓히려다 어긋나는 일이 있습니다. 지금은 `Ctrl+hjkl`이 대안입니다.
- 흩어진 객체는 Grasshopper 모드에서 Ctrl+클릭 후 `` ` `` → `gyy`.
- 비주얼 `p`는 비어 있습니다 (범위가 아니므로).
