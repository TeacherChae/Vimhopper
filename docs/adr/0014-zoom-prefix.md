# 0014. `z`를 접두어로: `zz`, `z{범위}`, 비주얼 `z`

- 상태: 제안 (2026-11-10, 2텀에서 이대로 진행)
- 관련: [리더 키, 컴포넌트 검색, 줌 — 3. 줌](../leader-and-zoom-ideas.md#3-줌), [로드맵 2텀](../roadmap.md#2텀-찾기와-점프)

## 맥락

지금 `z` 한 번은 커서 객체를 가운데로, `Ctrl+=` / `Ctrl+-`는 화면 중심 기준 확대·축소입니다. "이 범위를 화면에 맞춰 보기"가 없어서 큰 정의에서 마우스 휠에 의존합니다.

## 결정 (제안)

| 키 | 동작 |
|---|---|
| `zz` | 커서 객체를 가운데로 (지금의 `z`) |
| `z{범위}` (`zL`, `z2h`, `zp`) | 그 범위를 화면에 맞춤. 연산자 + 범위 문법 그대로 ([0010](0010-operator-range.md)) |
| 비주얼 `z` | 선택을 화면에 맞춤 |
| `Ctrl+=` / `Ctrl+-` | 유지. 기준점을 **커서 객체**로 바꿈 (확대해도 커서가 안 나감) |

- 화면에 맞출 때 최대 배율은 100%.
- 문서 전체 맞춤 키는 정하지 않음 (필요해지면).
- `z{범위}`는 문서를 바꾸지 않으므로 `.` 되풀이·undo 대상이 아닙니다.

## 결과

- 가운데 맞추기가 한 번 → 두 번으로 늘어납니다. 대신 줌이 다른 연산자와 같은 문법으로 읽힙니다.
- 2텀 시작 때 사용자 이의가 없으면 채택으로 바꿉니다.
