# 결정 기록 (ADR)

다시 논의하지 않도록 **이미 정한 것과 그 이유**를 모았습니다. 새 세션·새 에이전트는 작업 전에 이 목록을 훑고, 여기 있는 결정을 뒤집으려면 사용자에게 먼저 묻습니다.

- 상세한 동작은 [키맵](../keymap.md)과 주제 문서에 있고, ADR은 "왜 이렇게 했나"만 짧게 남깁니다.
- 상태: **채택**(지금 코드가 이렇게 동작) / **제안**(다음 텀에 이대로 진행, 시작할 때 확정) / **대체됨**(뒤의 ADR이 바꿈).
- 새 결정은 다음 번호로 [템플릿](template.md)을 복사해서 씁니다. 기능을 바꾸는 커밋에 같이 넣습니다.

## 구조

| 번호 | 결정 | 상태 |
|---|---|---|
| [0001](0001-core-engine-loader.md) | Core / Engine / 로더 셋으로 나누고 엔진은 핫 리로드 | 채택 |
| [0002](0002-key-hook.md) | 캔버스 HWND 서브클래싱으로 Grasshopper보다 먼저 키를 받음 | 채택 |
| [0003](0003-undo.md) | 문서를 바꾸는 명령은 모두 undo 기록 하나 (`u` 한 번) | 채택 |
