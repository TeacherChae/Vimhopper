# 0004. Vim 모드는 백틱으로 켜고 끔, Grasshopper 모드는 vim의 Insert

- 상태: 채택 (2026-10-28)
- 관련: [키맵 — 모드](../keymap.md#모드)

## 맥락

처음에는 vim처럼 `Esc`로 들어가고 `a`로 나왔습니다. 하지만

- Grasshopper에서 `Esc`는 이미 쓰입니다 (드래그 취소, 검색창 닫기). Vim 모드 안에서도 입력 중인 명령을 취소하는 `Esc`가 필요합니다.
- Grasshopper 모드는 글자를 치는 모드가 아니라 마우스로 다루는 모드라서 `a`/`i`로 "들어간다"는 비유가 맞지 않고, `i`는 연결(`i{n}`)에 써야 했습니다.

## 결정

- `` ` ``(백틱) 하나로 켜고 끕니다. 입력 중인 명령이나 비주얼 모드가 있어도 바로 나갑니다.
- Grasshopper 모드 = vim의 Insert (키가 원래 동작), Vim 모드 = Normal, `v` = Visual.
- 화면 좌하단에 `-- VIM(normal) --` / `-- VIM(visual) --`.

## 결과

- `Esc`는 두 모드 모두에서 원래 뜻 (Grasshopper: Grasshopper 동작, Vim: 취소).
- 백틱은 한국어 키보드에서도 `1` 왼쪽이라 손이 닿습니다.
- 키맵 설정 파일이 생기면 바꿀 수 있게 할 후보입니다 ([로드맵 4텀](../roadmap.md#4텀-명령줄과-설정)).
