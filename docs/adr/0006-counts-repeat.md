# 0006. 숫자는 반복 횟수, 번호로 고르는 이동은 `gi{n}` / `go{n}`

- 상태: 채택 (2026-10-28)
- 관련: [이동](../navigation.md), [키맵 — 이동](../keymap.md#이동)

## 맥락

처음에는 `{n}h`가 "입력 n의 출처로"였습니다. 그런데 연산자 범위 `d2h`는 "상류 2단계"라서 같은 `2h`가 이동과 범위에서 뜻이 달랐습니다.

## 결정

- 숫자는 vim처럼 **반복 횟수**입니다: `3l` = `l` 세 번, `d2h` = 상류 2단계. 끝을 넘으면 갈 수 있는 데까지 가고 멈춥니다. `0`은 숫자를 시작하지 않습니다.
- 번호로 고르는 이동은 `gi{n}`(입력 n의 출처) / `go{n}`(출력 n을 받는 객체)로 옮겼습니다. `i` = 입력, `o` = 출력은 연결 `o{n}` → `i{n}`과 같은 뜻입니다.
- 파라미터 번호는 0부터. 파라미터가 10개 이하면 한 자리로 즉시 확정, 11개 이상이면 더 붙일 수 없을 때나 `Enter`·다음 키로 확정합니다.

## 결과

- 이동, 범위, `.`의 숫자(`3.`)가 모두 "몇 단계"로 읽힙니다.
- 연산자 앞뒤 숫자는 곱합니다 (`2y3l` = 6단계, [0010](0010-operator-range.md)).
