# 리더 키, 컴포넌트 검색, 줌 (제안)

> 검토용 제안 문서입니다. 조사한 사실(Grasshopper API)과 논의 중인 선택지를 정리했습니다.
>
> **정한 것**: `:`는 Vimhopper 명령줄(4절), 컴포넌트 넣기는 `Space Space`, 줌은 `z` 접두어(3절, [0014](adr/0014-zoom-prefix.md)).

## 1. 리더 키

Grasshopper는 Space로 컴포넌트 검색창을 띄우므로, 지금은 Vim 모드에서도 Space를 Grasshopper에 넘기고 리더 키를 쓰지 않습니다 ([키맵](keymap.md#정렬)).

**기본 기능에는 리더가 필요 없습니다.** vim에서도 리더(`<leader>`)는 사용자가 자기 매핑을 얹으려고 비워 둔 자리이고, 기본 기능은 `z` `g` `[` `]` `Ctrl` 같은 접두어로 나뉩니다. Vimhopper도 기본 키는 `z`(화면), `g`(`g=`, `gy`, `gc`, `gi`/`go`) 접두어로 충분합니다. 리더가 실제로 필요해지는 것은 [로드맵](roadmap.md)의 키맵 설정 파일로 사용자 매핑을 열 때입니다.

| 방안 | 장점 | 단점 |
|---|---|---|
| `\` | vim의 원래 기본 리더, 충돌 없음 | 손이 멀어 자주 쓰기 불편 |
| `,` | nvim에서 흔한 대안, 지금 비어 있음 | vim의 `,`(반복 찾기)를 나중에 `f`/`;`와 함께 들여오면 겹침 |
| **Vim 모드에서만 Space를 리더로, 검색은 `Space Space` 또는 `:`** | Space 리더를 쓰면서 검색도 키 하나만 더. Grasshopper 모드의 Space는 그대로 | 검색에 한 번 더 눌러야 함 |

세 번째 방안이 유력합니다. 아래 2절의 API로 가능하다는 것을 확인했습니다. `:`로 검색창을 여는 것은 로드맵의 `:` 컴포넌트 생성과도 이어집니다.

## 2. 컴포넌트 검색창을 코드로 열기

Grasshopper.dll의 메타데이터와 NuGet 패키지의 `Grasshopper.xml` 문서로 확인했습니다 (Grasshopper 8.17). **Rhino에서 실제로 띄워 보지는 않았습니다.**

| API | 설명 |
|---|---|
| `GH_Canvas.ShowComponentSearchBox()` | Space·더블클릭과 같은 컴포넌트 검색창을 **마우스 위치**에. 성공하면 `true` |
| `GH_Canvas.ShowComponentSearchBox(Point at)` | 검색창을 **지정한 위치**에. `at`은 화면 좌표이고 검색창의 중심 |
| `GH_Canvas.ShowSearchDialog(bool centerOnCursor)` | 컴포넌트 추가가 아니라 캔버스 안 객체를 찾는 **찾기(Find) 창** (vim의 `/` 후보) |

- 문서에 적힌 제약: 캔버스의 `ModifiersEnabled`가 `false`면 검색창이 뜨지 않습니다.
- 검색창 클래스는 `GH_PopupSearchDialog`(문서에서 `<exclude/>`, 즉 내부용)입니다. `BasePoint` 속성은 "보통 검색창을 만들 때의 커서 위치"로 설명되어 있어, 새 컴포넌트가 이 점 근처에 놓이는 것으로 보입니다.

### 이것으로 할 수 있는 것

- Vim 모드에서 Space를 리더로 가져가도 `Space Space` / `:`로 같은 검색창을 띄울 수 있습니다.
- 마우스 위치가 아니라 **커서 객체 오른쪽**에 띄워서, 새 컴포넌트가 지금 작업하는 곳 옆에 놓이게 할 수 있습니다.
- 문서의 객체 추가 이벤트로 새로 놓인 컴포넌트를 잡으면, 커서를 바로 그 객체로 옮기거나 [vim에서 더 가져올 것](vim-ideas.md#5-바꾸기-c-끼워-넣기)의 끼워 넣기(지금 객체 → 새 컴포넌트 → 원래 자식)로 이어갈 수 있습니다.

### Rhino에서 확인할 것

1. **키 후킹과의 충돌**: 검색창은 캔버스와 다른 창입니다. 거기서 치는 글자가 `CanvasKeyHook`에 걸리지 않고 검색창으로 가는지.
2. **한글 IME**: Vim 모드는 캔버스의 IME만 끄므로 검색창에는 적용되지 않을 수 있습니다. 검색창에서 한글이 입력되는지, 그게 괜찮은지.
3. **놓이는 위치**: 위치를 지정해 띄웠을 때 새 컴포넌트가 그 근처에 놓이는지.

### 실험 (`feature/component-search`)

`Space Space`로 구현했습니다 ([키맵](keymap.md#넣기)). 커서 객체 오른쪽 끝에서 60(캔버스 좌표)만큼 떨어진 곳을 중심으로 검색창을 띄우고, 다음에 문서에 추가되는 객체로 커서를 옮깁니다. 위 세 가지는 Rhino에서 확인해야 합니다.

- 검색창은 Space의 키 메시지 처리가 끝난 뒤(`BeginInvoke`)에 띄웁니다. 처리 중에 띄우면 Space 글자가 검색창으로 들어갈 수 있기 때문입니다.
- 검색창을 닫은 뒤 다른 경로로 추가된 객체(붙여넣기 등)를 잘못 잡지 않도록, 캔버스에서 키를 누르면 기다리기를 멈춥니다.

## 3. 줌

> **정함** ([0014](adr/0014-zoom-prefix.md), 2텀 `feature/zoom`에서 구현): `z`는 접두어, `zz` 가운데로, `z{범위}`와 비주얼 `z`는 화면에 맞춤(최대 100%, 비주얼 모드에 머묾), `Ctrl+=` / `Ctrl+-`는 유지하고 커서 객체 기준. 문서 전체 맞춤 키는 정하지 않았습니다. 지금 동작은 [키맵](keymap.md#화면).
>
> 아래는 정하기 전의 검토 내용입니다.

정하기 전에는 `Ctrl+=` / `Ctrl+-`가 화면 중심 기준 확대·축소이고, `z`는 배율을 그대로 두고 커서 객체를 가운데로 옮겼습니다.

`z`를 vim처럼 접두어로 바꾸고, 줌도 [연산자 + 범위](keymap.md#연산자--범위)를 받게 하는 안:

| 키 | 동작 | vim에서의 근거 |
|---|---|---|
| `zz` | 커서 객체를 가운데로 (지금의 `z`) | `zz` = 커서 줄을 화면 가운데로 |
| `z{범위}` (`zL`, `z2h`) | 그 범위가 화면에 꽉 차게 | `yL`, `dL`과 같은 범위 문법 |
| 비주얼 `z` | 선택한 것을 화면에 맞춤 | 비주얼 모드 연산자와 같음 |
| (미정, 예: `zA`) | 문서 전체를 화면에 맞춤 (Grasshopper의 Zoom Extents) | |

### 정할 것

1. **`z`를 접두어로 바꿀지**: 바꾸면 지금 한 번(`z`)이던 가운데 맞추기가 두 번(`zz`)이 됩니다. 대신 "범위에 맞춰 보기"가 다른 연산자와 같은 문법으로 읽힙니다.
2. **확대·축소 키**: `Ctrl+=` / `Ctrl+-` 유지, 또는 `+` / `-` 한 키로. `-`는 지금 비어 있고 `+`는 Shift+`=`입니다.
3. **확대·축소 기준점**: 지금은 화면 중심입니다. 커서 객체를 기준으로 하면 확대해도 커서가 화면 밖으로 나가지 않습니다 (추천).
4. **화면에 맞출 때 최대 배율**: 객체 한두 개면 과하게 확대될 수 있으므로 상한(예: 100%)을 둘지.

## 4. `:` 명령줄

Grasshopper 검색창은 컴포넌트 넣기에 한정되지만, vim의 `:`는 모든 명령을 입력하는 자리입니다. 그래서 `:`는 검색창이 아니라 **Vimhopper 자체의 명령줄**(HUD의 입력줄)로 두고, 컴포넌트 넣기는 `Space Space`로 뗍니다.

- Grasshopper에는 명령줄이 없지만 메뉴 항목(저장, 다시 계산, 솔버 잠금, 프리뷰 모드, Bake 등)이 사실상 명령 목록입니다. 대부분 API로 부를 수 있을 것으로 보이나 하나씩 확인이 필요합니다.
- 가장 가까운 짝은 **Rhino 명령창**입니다. RhinoCommon의 `RhinoApp.RunScript`로 Rhino 명령을 실행할 수 있습니다.

| 명령 (예) | 동작 |
|---|---|
| `:w` / `:e 파일` | 저장 / 열기 |
| `:recompute`, `:lock` | 다시 계산 (F5), 솔버 잠금 |
| `:preview off` | 프리뷰 모드 |
| `:set ...` | 설정 (키맵 설정 파일과 연결) |
| `:g/패턴/명령` | 조건에 맞는 객체에 일괄 적용 ([vim에서 더 가져올 것](vim-ideas.md#7-그-밖에)) |
| `:rh _Line` (또는 `:!`) | Rhino 명령으로 넘기기 |

명령 이름과 범위는 아직 정하지 않았습니다. 먼저 `Space Space`(2절의 실험)를 만들고, 그다음 명령줄 입력 UI와 몇 개의 명령으로 시작합니다.
