# 로드맵

[nvim 조사](research/nvim.md)와 [Grasshopper 사용자 조사](research/grasshopper-users.md)를 바탕으로 텀(마일스톤) 단위로 나눴습니다. 작업 방식은 [CLAUDE.md](../CLAUDE.md), Rhino에서 확인할 것은 [검증 목록](verification.md)에 있습니다.

## 방향

- **문법이 먼저.** vim에 빠지는 이유 1·2위는 조합되는 문법(연산자 + 범위)과 `.` 반복입니다. 새 기능은 되도록 기존 연산자·범위에 얹습니다.
- **마우스보다 빠른 점프.** 큰 정의에서 길 찾기는 Grasshopper 사용자의 고질적인 불편이고 기본 기능으로는 풀리지 않습니다 (상류 검색 없음, 키보드 단축키 거의 없음 — McNeel은 한 글자 단축키를 당분간 넣지 않겠다고 했습니다, RH-68139).
- **읽기 쉬운 정의.** 스파게티 와이어, 데이터 트리, 경고 연쇄가 질문의 대부분입니다. 정렬(`==`) 다음은 "보이게 하기"입니다.
- **발견성.** 키가 늘어날수록 which-key 같은 안내가 필수입니다.

## 1텀: 문법 완성 (`term/1-grammar`)

| 작업 | 키 | 근거 |
|---|---|---|
| 반복 | `.` (앞 숫자는 횟수를 바꿈) | vim 와우 포인트 2위 |
| 다음 키 안내 (which-key) | 접두어(`g` `d` `y` `=` `gc` `gy` `Space`) 뒤 잠시 멈추면 HUD에 다음 키 목록 | 발견성 |
| 점프 기록 | `Ctrl+o` 뒤로 / `Ctrl+i` 앞으로. `gi`·`go`, 숫자 이동, 넣기, `{`·`}`가 기록됨 | `h`/`l`이 서로 역이 아닌 문제를 덜어 줌 |
| 연결 강조 | Vim 모드에서 커서 객체의 입력·출력 와이어 강조, `h`/`l` 대상 미리 표시 | 스파게티 와이어 1위 |
| 덩어리 범위 | 연산자 뒤 `p` = 와이어로 이어진 덩어리 (`yp` `dp` `gcp` `=p`=`==`), `{` / `}` 이전·다음 덩어리 | vim의 문단(`ip`, `{`·`}`) |

## 2텀: 찾기와 점프

| 작업 | 키 |
|---|---|
| 라벨 점프 (flash) | `s` 누르면 보이는 객체마다 1~2글자 라벨, 라벨을 치면 그리로. 연산자 뒤에도 (`ys{라벨}`), 원격 연결 (`o0 s{라벨} i1`) |
| 찾기 | `/` 이름·별명·종류, `n` / `N`, `*` 같은 종류의 다음 객체 |
| 마크 | `m{a}` / `'{a}` |
| 붙여넣기 | `p` 커서 오른쪽에 붙이고 커서를 붙인 객체로 |
| 줌 정리 | `zz` 가운데로, `z{범위}` 범위에 맞춰 보기, 비주얼 `z` ([제안](leader-and-zoom-ideas.md#3-줌)) |

## 3텀: 읽기와 진단

| 작업 | 키 |
|---|---|
| 오류·경고 목록 | `]e` / `[e` (원인인 객체만), `]w` / `[w` 경고 |
| 데이터 모양 보기 | `K` 커서 객체 출력의 트리 모양, 입력 간 불일치 힌트 |
| 그룹 연산자 (surround) | `gG{범위}` 그룹으로 묶고 이름 붙이기, `]g` / `[g` 그룹 사이 이동 |
| 느린 객체 | `]s` / `[s` 느린 순 이동, 상위 N개 시간 표시 |
| 이름 바꾸기 | `cn` 커서 객체 별명 바꾸기 |

## 4텀: 명령줄과 설정

| 작업 | 키 |
|---|---|
| 명령줄 | `:` HUD 입력줄, `:w` `:recompute` `:rh {Rhino 명령}` ([제안](leader-and-zoom-ideas.md#4--명령줄)) |
| 일괄 이름 바꾸기 | `:s/옛/새/` (범위·비주얼 선택에) |
| 키맵 설정 파일 | `:set`, 리더 매핑 |
| Slider 값 | `Ctrl+a` / `Ctrl+x` (숫자로 배수) |

## 그 뒤

- 클러스터: `gC{범위}` 클러스터로 만들기, 같은 클러스터 인스턴스 사이 이동
- `.gh` 비교용 텍스트 내보내기, `]c` / `[c` 바뀐 객체 사이 이동
- 자동 정렬 개선: 결과 패널 빼기, Network Simplex 열 나누기, 줄기 가중치 세로 배치 ([조사](formatting-research.md))
- 의미상 단계로 묶기 ([자동 정렬](formatting.md#남은-문제-의미상-단계와-그래프-깊이가-어긋남))
- `h`/`l`이 막히는 경우 개선 ([이동](navigation.md#미해결-부모-없음--자식-없음이-자주-나옴))
- Rhino 9 (.NET 10) 대상 추가

## 끝난 것

- hjkl (자동 정렬과 같은 기준, [이동](navigation.md)), 숫자 반복, `gi{n}` / `go{n}`
- 자동 정렬 `==` / `g=`, Relay 자동 배치 ([자동 정렬](formatting.md))
- 연결 `o{n}` → `i{n}`, 데이터 연산 `f` `g` `s` `r`, 와이어 끊기 `di{n}` / `do{n}`
- 연산자 + 범위: `y` `gy` `=` `d` `gc` 뒤에 `h` `l` `{n}h` `H` `L`, 실행 취소 `u` / 다시 실행 `Ctrl+r`
- 비주얼 모드 `v` (`o`, `H` / `L`, `u`로 선택 되돌리기)
- 컴포넌트 넣기 `Space Space`
