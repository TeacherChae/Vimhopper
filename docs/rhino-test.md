# Rhino 테스트 체크리스트 (1~4텀)

Rhino 8에서 1~4텀 기능을 한 번에 따라 해 보는 순서입니다. 시험용 정의 하나를 만들어 두고 위에서부터 진행합니다. 항목마다 기능의 대표 동작만 넣었고, 경계 경우는 [검증 목록](verification.md)에 있습니다.

- ★ 표시는 Rhino에서만 알 수 있어서 가장 위험한 것입니다. 시간이 없으면 ★만 봅니다.
- 이상하면 항목 옆에 `→ 실제: …`로 적습니다. 상태줄 문구, 그때 누른 키, 한/영 상태를 같이 적으면 고치기 쉽습니다.
- 끝까지 약 60~90분.

## 0. 준비

- [ ] `git pull` → `dotnet build` (경고 0) → 처음이면 `scripts\link-dev.ps1`
- [ ] Rhino 8 → `Grasshopper` → 캔버스 클릭 → `` ` `` → 좌하단 `-- VIM(normal) --`
- [ ] 핫 리로드: Rhino를 켠 채 `scripts\watch.ps1` 실행, 아무 `.cs`나 저장 → 명령창 `Vimhopper: engine reloaded`, Vim 모드와 커서 유지

### 시험용 정의 만들기

Grasshopper 모드에서 마우스로 아래를 놓고 별명을 바꿔 둡니다. 정렬은 나중에 `g=`로 하니 대충 놓습니다.

| 별명 | 컴포넌트 | 설정 | 연결 |
|---|---|---|---|
| `A` | Number Slider | 정수, 0..10, 값 3 | → `더하기`의 A |
| `B` | Number Slider | 실수 소수 2자리, 0..1, 값 0.25 | → `더하기`의 B |
| `더하기` | Addition | | → `곱하기`의 A |
| `곱하기` | Multiplication | B는 비워 둠 (경고) | → `결과` |
| `결과` | Panel | | |
| `홀수` | Number Slider | 홀수(Odd), 1..9, 값 7 | 연결 없음 |
| `스위치` | Boolean Toggle | | 연결 없음 |
| `글자` | Panel | 내용 `abc` | → `오류1`의 A |
| `오류1` | Addition | | → Relay → `오류2`의 A |
| `오류2` | Multiplication | | |
| `열` / `셋` | Series 두 개 | Count 10 / Count 3 | → `짝`의 A / B |
| `짝` | Addition | | |
| `반지름` | Number Slider | 0..10 | → Circle의 Radius |
| | Circle | | |

- [ ] 별명 `글자` 패널 → `오류1`이 빨강(오류), 그 하류 `오류2`도 오류. `곱하기`는 주황(경고)
- [ ] 저장: `test.gh` (`:w`와 `gy`에 경로가 필요)

## 1. 기본과 1텀 (문법)

### 이동·강조·힌트

- [ ] `A`를 마우스로 선택 → `` ` `` → `l` `더하기`, `l` `곱하기`, `h` 돌아옴, `j` / `k` 같은 열 위아래
- [ ] ★ 연결 강조: 커서 객체의 입력 와이어 파랑, 출력 자주색 굵게, Grasshopper 곡선과 정확히 겹침 (확대·축소 몇 단계)
- [ ] `h` / `l` 표시(파랑·자주 외곽선)가 붙은 객체로 실제 `h` / `l`이 감
- [ ] `gi0` 입력 0의 출처로, `go0` 출력을 받는 쪽으로, `Ctrl+h/j/k/l` 화면 방향
- [ ] `}` / `{` 덩어리 사이, `3}` 세 개 건너뜀, 끝에서 `다음 덩어리 없음`
- [ ] `Ctrl+o` / `Ctrl+i` 점프 목록. ★ Vim 모드의 `Ctrl+O`가 파일 열기 창을 띄우지 않음
- [ ] `g`, `y`, `d`, `2` 뒤 0.4초 → 다음 키 힌트 패널, 빨리 치면(`g=`) 뜨지 않음
- [ ] ★ 한/영을 한글로 둔 채 Vim 모드 → `h`가 `ㅗ`가 아니라 이동, Vim 모드를 나가면 한글 입력 복구

### 연결·데이터 연산

- [ ] `A`에서 `o0` (주황 원) → `l` 두 번 → `i1` → `곱하기`의 B에 연결, 경고 사라짐
- [ ] `o0f` flatten 표시, 다시 `f`로 꺼짐. `i0g` graft
- [ ] `di1` 입력 1 와이어 끊기 → `u` → 되돌아옴

### 연산자 + 범위, 되풀이, 정렬

- [ ] `yL` → `Ctrl+V` 하류 전체 붙여넣기 → `u`
- [ ] `dd` → `u` 한 번에 객체와 와이어가 돌아옴, `Ctrl+r` 다시
- [ ] `gcH` 상류 전체 끄기 → 다시 `gcH` 켜기. `gcc` 한 개
- [ ] `dp` 덩어리 삭제 → `u`
- [ ] `d2l` → `j` → `.` 되풀이 → `u` 두 번
- [ ] `==` 지금 덩어리 정렬, `g=` 문서 전체 정렬, Relay가 알아서 들어가고 빠짐, `u` 한 번에 원래 배치
- [ ] `gyy` → 메모장에 붙이면 `…test.gh:GUID`

### 비주얼 모드·넣기

- [ ] `v` → `jj` → `L` → `y` → `Ctrl+V` 선택만 붙음. 비주얼 `u`로 선택 되돌리기
- [ ] ★ `Space Space` → 커서 객체 오른쪽에 검색창, Space 글자가 검색창에 안 들어감, 검색창에서 한글 입력
- [ ] `o0` → `Space Space` → Panel 넣기 → `i0`으로 바로 연결

## 2. 2텀 (찾기와 점프)

### 라벨 점프

- [ ] ★ `t` → 보이는 객체마다 분홍 라벨, 가까운 객체가 `a` `s` `d`. 라벨 치면 이동, `Ctrl+o`로 돌아옴
- [ ] `o0` → `t{라벨}` → `i1` 먼 객체에 연결
- [ ] `yt{라벨}` → `Ctrl+V` 커서~라벨 블록
- [ ] 객체가 27개 넘게 보이도록 `yp` `Ctrl+V` 몇 번 → `t` 두 글자 라벨, 첫 글자 치면 나머지 사라짐 → `u`로 정리

### 찾기

- [ ] `/더하` → 노란 테두리·`[1/2]`, `Enter` 이동, `n` / `N`, 끝에서 `search hit BOTTOM, continuing at TOP`
- [ ] ★ 한/영 한글로 `/반지` → 조합 중 글자가 입력줄에 주황 밑줄, `Enter`로 `반지름` 찾음. 닫은 뒤 `h`가 `ㅗ`로 안 바뀜
- [ ] `/` 입력 중 `Esc` → 커서·화면이 원래대로
- [ ] `A`에서 `*` → 다음 Number Slider, `#` 이전

### 마크·붙여넣기·줌

- [ ] `A`에서 `ma` → 멀리 이동 → `'a` 돌아옴. `y'a` 커서~마크 블록 복사
- [ ] ★ `yy` → 다른 객체에서 `p` 오른쪽에 붙고 커서가 붙인 것으로, `P` 왼쪽. 밖에서 오던 입력 와이어도 `Ctrl+V`처럼 이어짐
- [ ] `p` 뒤 `u` 한 번에 모두 사라짐
- [ ] `zz` 가운데로, `zL` 하류를 화면에 맞춤, `zp` 덩어리, 비주얼 `z`
- [ ] `Ctrl+=` / `Ctrl+-` 확대·축소해도 커서 객체가 제자리

## 3. 3텀 (읽기와 진단)

- [ ] ★ 어디서든 `]e` → `오류1`에만 감 (`오류2`는 하류라 건너뜀), 상태줄 `오류 원인 1/1 (오류 2개)`
- [ ] `]w` → `곱하기`(B를 끊어 두었으면)로
- [ ] Vim 모드에서 느린 객체 옆에 `ms` 시간 표시, `]s` / `[s` 느린 순
- [ ] ★ `짝`에서 `K` → 입력 A 가지·항목 10, B 3, `B: 항목 3개 …` 재사용 힌트. `j`로 닫히고 이동
- [ ] `열`에 `i0f`(flatten)를 걸고 `K` → 개수가 적용 뒤 값
- [ ] ★ `A`에서 `gGp` → 초록 점선 → `입력` `Enter` → 덩어리를 감싼 그룹. `Ctrl+G` 그룹과 같은 모양, 다른 객체를 덮어 그리지 않음
- [ ] 한글 그룹 이름 `gGG` → `반지름` `Enter`, `u` 한 번에 그룹만 사라짐
- [ ] `]g` / `[g` 그룹 사이 이동
- [ ] ★ `더하기`에서 `cn` → `별명: 더하기` → `합`으로 고쳐 `Enter`, `u`로 원래대로. 빈 `Enter`는 기본 별명 `A+B`

## 4. 4텀 (명령줄과 설정)

### 슬라이더 값

- [ ] `B`에서 `Ctrl+a` → 0.26, `5Ctrl+x` → 0.21, 바로 다시 계산. `u` 한 번씩
- [ ] `홀수`(7)에서 `Ctrl+a` → 9, 한 번 더 → `최댓값입니다`
- [ ] `스위치`에서 `Ctrl+a` → 뒤집힘
- [ ] ★ Vim 모드에서 `Ctrl+A`가 모두 선택을, `Ctrl+X`가 잘라내기를 하지 않음. Grasshopper 모드에서는 원래대로

### 명령줄

- [ ] `:` → 입력줄, `:w` 저장 (탭 제목 `*` 사라짐)
- [ ] `:rec` 다시 계산, `:lock` → 슬라이더를 움직여도 계산 안 됨 → `:unl`
- [ ] `:rh _Circle 0,0,0 5` → Rhino에 원
- [ ] ★ `:re` `Tab` → `:recompute` 완성. `Tab`이 입력줄로 오지 않고 포커스가 넘어가면 적기
- [ ] ★ `↑` / `↓` 기록, 방향키가 객체를 움직이지 않음
- [ ] `더하기`에서 `:s/더/Plus /` → `Plus 하기`, `u`
- [ ] `:%s/a/A/g` → 상태줄 `n개 바꿈`, `u` 한 번에 모두
- [ ] 비주얼로 두 개 고르고 `:` → `:'<,'>` 채워짐 → `s/^/X_/` `Enter` → 고른 것만

### 설정 파일

- [ ] ★ `%APPDATA%\Vimhopper\vimhopperrc` 를 만들고 아래를 넣은 뒤 Rhino를 다시 켜고 첫 `` ` ``:

  ```vim
  " 시험용
  nnoremap <leader>w :w<CR>
  nnoremap <leader>f /반지름<CR>
  nmap Q dd
  set hintdelay=200
  ```

- [ ] `Space` → 0.2초 뒤 힌트에 `w` `f` 매핑, `Space w` 저장, `Space f` → `반지름`으로 이동, `Q` 삭제 → `u`
- [ ] `Space Space`는 여전히 검색창
- [ ] `:map` 목록, `:set hintdelay?` → `hintdelay=200`
- [ ] 파일에 `set foo=1` 줄을 넣고 `:so` → 상태줄 `vimhopperrc …행: 알 수 없는 옵션: foo`

## 5. 정리

- [ ] `` ` ``로 나가면 강조·라벨·패널·입력줄이 남지 않음, 한/영 상태가 원래대로
- [ ] 다른 `.gh` 탭으로 바꿔도 `hjkl`, 강조, `]e`가 새 문서에서 동작
- [ ] 큰 정의(수백 개 객체)에서 패닝·확대·`hjkl`이 느려지지 않음
- [ ] 다 했으면 [검증 목록](verification.md)의 같은 항목도 체크하고, 이상한 것은 이슈나 이 문서 옆에 적어 주세요 (`fix/` 작업으로 고침)
